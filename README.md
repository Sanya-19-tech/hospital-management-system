🏥 Hospital Management System
🚀 Full Stack Web Application

Built using Angular + ASP.NET Core Web API + SQL Server

🔹 Tech Stack

Frontend: Angular 21

Backend: ASP.NET Core (.NET 10)

Database: SQL Server (LocalDB)

ORM: Entity Framework Core

API Testing: Swagger

Version Control: Git & GitHub

🔹 Features

✔ Add Patient
✔ View Patient List
✔ Update Patient
✔ Delete Patient
✔ REST API Integration
✔ CORS Configuration
✔ Bootstrap Professional UI

🔹 Project Structure
HospitalManagementSystem
 ├── HospitalAPI (Backend - .NET)
 └── hospital-ui (Frontend - Angular)

🔹 How To Run
Backend

Open HospitalAPI in Visual Studio

Run project

Swagger will open

Frontend
cd hospital-ui
ng serve


Open:

http://localhost:4200
